================
Lead + Promotion
================

Glue module between *Lead* and *Promotion*. It lets a lead record the valid
promotion codes claimed on it, so a code coming from a portal form is
validated by a relation to the promotion code master instead of free text
matching.

The relation is claim information only. It does not redeem the codes, does
not create any promotion code usage, and does not deduct any amount.
